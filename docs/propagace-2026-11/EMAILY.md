# E-maily k odeslání

Nic z toho nebylo odesláno. Kontakty pocházejí z veřejných stránek daných webů k 4. 11. 2026.

**Před odesláním:**

- Otevřete si stránku závodu a zkontrolujte, že údaje sedí a chyby z [PLAN.md](PLAN.md) jsou opravené.
