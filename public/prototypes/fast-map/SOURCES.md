# Prototype assets

- Leaflet 1.9.4: https://www.npmjs.com/package/leaflet/v/1.9.4. BSD-2-Clause; license alongside the library.
- City names, coordinates, population and capital status: https://download.geonames.org/export/dump/cities15000.zip, retrieved 2026-10-15. Selected European countries, population >= 15,000; sorted by population and coordinates rounded to four decimals. GeoNames CC BY 4.0: https://www.geonames.org/export/.
- Basemap: existing CARTO Voyager without labels, attribution retained in the map.
- Race data and discipline icons: existing LetsRace public catalog and assets.

The city dataset is a prototype label layer, not a complete street/village gazetteer.
